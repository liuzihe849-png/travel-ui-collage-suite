# Confirmed city objects

When the user supplies specific objects, follow that list. When only a city is supplied, curate 1–2 recognizable local physical accents yourself and briefly explain the choice; proceed unless the user asks to review choices first. Do not silently treat missing objects as an empty list. If the user says no objects, omit them. If the city is unknown or intentionally omitted, do not infer it from the photo. The Apple interface and source traveler remain the focus; objects are small supporting details, not a decorative sticker border.

- Use each confirmed object once unless the user requests repetition. Prefer an object already in the source photo; otherwise place it at a believable scale and perspective.
- In photo-overlay mode, retain the original setting. Do not invent a landmark or reimagine the location to match the city. In Freeform mode, objects can sit sparingly in the open dotted canvas without obscuring the person's face or hands.
- Keep recognizable object anatomy and source-like lighting. An abstract choice such as music may use one compact UI/media cue instead of an invented physical souvenir.
- For inserted physical objects, composite the cleaned transparent asset directly: no programmatic shadow from its alpha mask, offset black silhouette, glow, rim, or heavy pre-baked shadow. If a generated asset already contains such a shadow, remove it or regenerate the asset before use. Integrate through believable scale, perspective, color, and light instead.
- Keep accents within the selected city palette and 1–2 object groups. Do not add unrelated fans, coins, receipts, flags, seals, tickets, or gold ornaments. Do not fabricate official text, dates, prices, booking codes, or historical claims.

Examples: `熊猫` → one panda cue without a bamboo border; `火锅` → one recognizable Sichuan hotpot without an invented restaurant/menu; `民谣` → one Music-like media card, waveform, or musical object already in the source, with no invented song title or lyrics; `折扇` or `铜钱` → one physically believable object, not a repeated motif.

Record the selected objects, visible count, and absence of added object shadows in the final QC handoff. The user's list is a limit, not permission to expand the palette.

## City curation examples
These are flexible visual candidates, not claims about the user's itinerary or mandatory stereotypes. Shanghai: one white magnolia blossom branch and a small xiaolongbao steamer; Beijing: blue-and-white porcelain and a copper hotpot; Chengdu: one panda cue and a Sichuan hotpot. Use the user's preference when provided. For unfamiliar cities, verify the proposed cultural association with reliable sources before presenting it as local.

Place one accent in an open upper-left/side area and the second in opposite side whitespace if space permits. Avoid covering face, hands, UI labels or the greeting. Accents can lightly overlap a UI edge to establish layer relationships, but must retain clean transparent edges and have no added cast/drop shadow. Do not make the objects equally large or arrange them as a border. A flower branch is one group; a steamer with its dumplings is one group.
